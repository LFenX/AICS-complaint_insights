# 日报表格与日志导出 PRD

用户：本机研发、运营审阅者。目标：用最少滚动查看有UID或附件的来信，并从具体子问题直接获取日志。

布局：删除底部解释及版本尾栏，信息仍可在口径面板查看；桌面容器距文档底部20px、移动16px。表格9列：UID、发件/送达邮箱、主题/摘要、正文、图片、日志、其他文件、分类、详情。原译切换及邮箱/UID/附件证据保持可用。

交互：筛选工具行增加“优先排序”，四种有内容优先，默认UID。筛选、分页和排序互不丢数据，换排序回第一页。子问题工具行显示日志ZIP入口，必须先选具体子问题；无日志显示禁用原因。有日志显示全部文件数、涉及邮件数，整组下载不受当前页/搜索/小时限制。

约束：生产保持隔离、不重新读取IMAP、不改变634封分类；不开放新网络监听。ZIP仅包含本组原始日志和manifest，绝不夹带邮件正文或账号配置；原始日志内容保持字节相同。ZIP在读取模型构建阶段预生成，GET不压缩、不查数据库。入口沿用本机身份边界并新增独立export能力、Feature禁用原因和元数据审计。文件名清洗，固定ID索引、版本校验，未知/越权/关闭时拒绝。

验收：底部自然留20px且无旧尾句；UID首列、无时间主键列；四种排序均有内容在前且分页全集634不丢；35个ZIP覆盖86个日志，清单/归属/字节摘要一致、无穿越；所有禁用/403/404/409路径、权限父链、Feature与审计有测试；实际浏览器选择子问题并下载验证；用户验收Pending。
