# 日期与每日生成设计

## 用户与页面

研发、运营通过3030看板选择北京时间业务日期，查看该日已生成日报。进入无date参数的页面默认今天；显式date链接打开对应日期。标题中的日期改为带文字标签的原生日期输入，旁边提供今天与已生成日期快捷选择。切换立即移除旧报告内容，等待期间显示加载状态，未生成显示“日报未生成”；保留日期入口，不自动跳回10月29日。读取或校验失败单列为“日报读取失败”，不冒充未生成。

保持白底、现有字体和红紫青绿配色。已生成页顺序不变：结论→三核心指标→排行→原信和分页→三补充指标→两张图。历史日期的“昨日”改称“当日”。空状态用现有边框、间距与字体，页面其余区域不展示旧图表或旧原信。

## 数据契约

- 默认读取目录`.runtime/daily-reports/YYYY-MM-DD/report.json`，严格验证日期格式和真实日期，不接受路径或重复date参数。
- `GET /data.json?date=YYYY-MM-DD`返回`report_status=generated|not_generated`、`business_date`、`today`、`available_dates`、`timezone`。生成状态附现有读取模型和SHA；缺失不附旧记录。无参数按服务器北京时间今天。
- `/mail/{id}`、`/file/{id}`、`/file/{id}/preview`、`/log-archive/{id}`均携带相同date与版本。详情和附件限定在该日期报告索引，缺日返回404，版本漂移返回409。
- 页面请求只读文件，不访问数据库；按日期限制缓存数量。原有LAN真实对端、Host/Origin、权限、Feature与审计保留。无新的匿名入口或写接口。
- 切换清空筛选、侧栏和详情缓存，释放图表，使用请求代次屏蔽旧异步响应；URL携带所选日期，前进后退与今天按钮可用。

## 日报生成

新增日期化本地准备/发布入口，复用既有正文、UID、主组聚合、附件预览与日志ZIP模块。冻结本地15433副本时使用reader、read-only repeatable-read；不调用source_connection、watch或生产库。

每次生成在独立工作目录冻结全天RECEIVED集合、15日总量、原文/译文、原分类、附件元数据与真实引用链上下文。Agent逐封审阅并输出绑定快照SHA的review和语义分类定义；不能按关键词脚本推导摘要、UID或分类。生成器只校验、组装和计算。

发布前要求日终水位、完整集合、每封摘要/依据/来源、语义分组、计数、UID证据、附件/ZIP校验通过。数据不足时留下任务状态与缺口，保持未生成；不以0封或旧日数据代替。完整0封须有日终覆盖证据。只以原子目录发布新日期，默认拒绝覆盖已有报告；同一输入重复执行返回已有同版结果。

## 验收

默认今天空状态、10月29日完整报告、非法日期、跨日期同ID隔离、快速切换、详情/附件/ZIP与原译/筛选/分页实测；历史report SHA保持原值。skill需覆盖历史原文及后续每次纠偏，并实际验证命令与失败阻断。调度按北京时间每天00:30接续本会话生成前一天，创建后回读配置，不宣称未到时间的自动运行已成功。
