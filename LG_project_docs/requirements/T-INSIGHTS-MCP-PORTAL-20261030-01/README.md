# MCP内网接入门户

- discovery/survey.md：原话、勘察与所有者发放权限。
- prd/portal.md：角色、页面、风险、审计、禁用原因及契约。
- design/technical-design.md：认证、存储、网络与失败设计。
- release/client-guide.template.md：说明模板；client-guide.md与tools-schema.json：实际schema生成的接入参考。
- release/operator-handoff.md：唯一所有者登录、运行、材料重建与回滚，不含密码。
- verification/results.json：真实HTTPS结果；coverage.json/report.md：原话逐条覆盖；delivery-files.json：交付文件哈希；listeners.json和layout-results.json：运行与布局证据。
- ui-previews/desktop.png、mobile.png：匿名首页实测HTML的桌面与窄屏渲染。

功能已实现和工程验证通过；正式人类门禁与用户验收Pending，异机路由未实测。
