> 提供查询不同数据的接口

> 并给出说明，注意接口工具以MCP形式构建，并提供相关说明，后续方便和其他人交接如何使用这些工具，按需调用所需数据

该回复没有批准安全隐私门禁，不将其记为通过。用户明确授权将已有本地查询能力以 MCP 交付，并补齐按数据类型选择工具、参数、分页、连接和交接说明。生产操作边界保持原指令。

实现判定：MCP 客户端可完成初始化、发现只读工具并查询分类、日期汇总、邮件原文及十四张业务表副本；工具具有结构化输入、输出与错误；提供公开配置模板和可运行客户端，实际令牌只放私有交接文件。MCP 通过本地鉴权 API 读取既有独立读取模型，禁止任意 SQL、源库写入和生产管理能力。

备选：只保留 HTTP/SQL 不满足用户指定的 MCP 入口；MCP 直接查询 PostgreSQL 可减少一跳，但会重复参数、分页和权限规则。选择 MCP 适配既有 HTTP 查询层，复用权限、审计、读取模型和版本游标。
