## 已核验事实

- 原项目为 `D:/LFEN_project/dev_project/AI客诉系统`；本期不改动其源码、配置、结构及命名。
- 开发源库为 `127.0.0.1:5432/ai_complaint_mail`，PostgreSQL 17；源邮件在 `public`，AI 产物在 `complaint_app`。
- 实查时源邮件 53,119 封，AI 产物 35,544 行，问题绑定 18,396 行；正式导入时重新核验，不将旧计数作为固定断言。
- 原始邮件包含完整正文和附件元数据；附件文件本体不在数据库。
- `messages.id -> InboundMail.sourcePk -> MailAiArtifact.inboundMailId -> MailIssueBinding.mailAiArtifactId` 是关联主链。
- 正式分类同时依赖三个部署 JSON 文件和数据库动态候选；生产报告的三个 SHA256 与开发文件一致。
- `categoryAi` 是原始 AI 建议；`category` 包含流水线归一处理；不读取人工覆盖表。
- 源邮件日志包含 I/U/D；应用日志有 7 天保留期、序号空缺和无旧值/新值的失效事件。
- 部分分类表、附件与文件夹没有事件；不能统一使用 `updatedAt`，也不能把日志 ID 连续性当成完整性证明。
- 归档表保存跨文件夹移动映射和旧快照；不能重复计入当前邮件总数。
- 时间归一应兼容单行历史偏移，不能写死全库减 8 小时；业务日采用 Asia/Shanghai。
- Docker 可用，`postgres:17-alpine` 已缓存，15433 与 3036 在勘察时空闲。
